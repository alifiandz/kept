# Kept development history

The application was developed through 37 source commits from August 27 to October 4, 2026. The original public full-source import was a single snapshot; it did not represent the start or extent of development.

The real development lineage is now preserved alongside the existing GitHub history. Original source dates, author labels, and parent relationships were retained. Author contact emails were anonymized and only audited public paths were retained, so restored commit hashes differ from the private originals.

Generic “Update Site source” messages have descriptive titles derived from their actual changed files. The original message and source commit are recorded in each commit body. No development dates, code changes, or activity were fabricated.

The final public-release preparation commits separate the real standalone-branding cleanup, portable metadata, documentation, and hosting preparation made for publication. They do not claim those changes happened earlier. The previous import snapshot is also preserved on an archive branch.
